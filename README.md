## Domain: Healthcare
## Problem: Medical Image Triage Using CNN

## Overview
This report presents an AI-based solution design for automating 
medical image triage in hospitals and diagnostic centers using 
Convolutional Neural Networks (CNN) and transfer learning.

## Tasks Completed
- Task 1: Business Domain Selection (Healthcare)
- Task 2: Business Problem Definition
- Task 3: AI Task Type Identification (Image Classification)
- Task 4: Data Requirement Plan
- Task 5: Model Recommendation (ResNet50 Transfer Learning)
- Task 6: Evaluation Plan
- Task 7: Responsible AI Considerations
- Task 8: Final Solution Summary

## Key Highlights
- Problem: Slow manual review of medical scans
- Solution: CNN-based image classification
- Model: ResNet50 fine-tuned on medical images
- Expected Impact: 60% reduction in triage time
- Risk Mitigation: All predictions reviewed by licensed radiologist
